# assets/og-image.jpg (pendente)

Este diretório deve conter `og-image.jpg`, a imagem usada nas tags `og:image` e
`twitter:image` do `index.html` para pré-visualização ao compartilhar o link do
site (WhatsApp, Facebook, Instagram, etc.).

Requisitos antes do lançamento das campanhas:

- Nome do arquivo: `og-image.jpg`
- Dimensões: 1200x630px
- Deve representar a marca CHAMA Marketing (logo + identidade visual do site)
- Peso recomendado: até 1MB, para carregamento rápido nos previews

Sem esse arquivo, plataformas sociais vão exibir um preview quebrado ou sem
imagem ao compartilhar o link do site.
